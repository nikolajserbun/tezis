# 30 сценариев коротких видео для эксперта

Демонстрационный материал из магазина «Тезис». Замените его своим продуктовым файлом перед запуском.

## Формула сценария

1. **Хук 0–3 сек.** Конкретная боль или неожиданное утверждение.
2. **Проблема 3–7 сек.** Пример из жизни аудитории.
3. **Решение 7–20 сек.** 2–3 шага, по одному на кадр.
4. **Доказательство 20–25 сек.** Мини-кейс или личный опыт.
5. **CTA 25–30 сек.** Одно действие: сохранить, написать слово, перейти по ссылке.

## Технические заметки

- Субтитры обязательны: значительная часть аудитории смотрит без звука.
- Первый кадр — лицо или крупный предмет, без долгих заставок.
- Один сценарий — одна мысль, без попытки уместить всё.
- Снимайте вертикально, следите за светом и стабильностью кадра.
- Не используйте чужие кейсы и отзывы без разрешения.
